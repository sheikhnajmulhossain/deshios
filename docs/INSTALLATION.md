# Installing DeshiOS 26.08 RC1

1. Download the ISO from the official release location.
2. Verify its SHA256 checksum.
3. Write the ISO to a USB drive using an image writer such as balenaEtcher.
4. Boot the PC from the USB.
5. Try the live environment if desired.
6. Start the graphical installer.
7. Carefully choose the intended disk or partitions.
8. Finish installation and reboot.

Back up important data before changing partitions. Secure Boot should currently be considered unsupported unless specifically validated.
