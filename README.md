## DeshiOS

DeshiOS is an open source desktop operating system project developed in Bangladesh 🇧🇩.

The project focuses on providing a clean, responsive and customizable desktop experience while giving users freedom and control over their computers.

DeshiOS is designed to be approachable for everyday computer users while remaining open and flexible for developers, enthusiasts and advanced users.

> DeshiOS is currently under active development. The current public release is intended for testing, experimentation and community feedback.

## Why DeshiOS?

DeshiOS is being developed around a few simple ideas.

### Clean desktop experience

A modern desktop designed to stay visually clean and comfortable for everyday use.

### Performance

DeshiOS aims to provide a responsive experience without requiring unusually powerful hardware.

### Freedom and control

Users should remain in control of their computers. DeshiOS is built around open source technologies and avoids unnecessary restrictions.

### Try before installing

The Live ISO allows you to boot DeshiOS from a USB drive and explore the operating system before installing it to your computer.

### Graphical installation

DeshiOS includes a graphical installer designed to make installation easier for normal desktop users.

### Customizable

Users can customize their desktop, applications and system according to their own preferences.

### Built in Bangladesh 🇧🇩

DeshiOS is an independent open source project developed in Bangladesh with the goal of contributing to the wider Linux and open source ecosystem.

---

## What is DeshiOS?

DeshiOS is a Linux distribution.

The current generation of DeshiOS uses **Debian 13** as its foundation and **GNOME 48** as its desktop environment.

Rather than simply presenting an unchanged upstream installation, the project combines its own system configuration, visual identity, installer configuration, boot experience, selected applications, hardware support choices and other changes into the DeshiOS experience.

DeshiOS builds upon the work of Debian, GNOME, the Linux kernel and thousands of projects and contributors throughout the free and open source software community.

## Hardware Requirements

These requirements apply specifically to **DeshiOS 26.08 RC1**. Future DeshiOS releases may have different requirements.

### Minimum

| Component | Requirement |
|---|---|
| Processor | 64 bit Intel or AMD processor with at least 2 cores |
| Memory | 4 GB RAM |
| Storage | 20 GB free space |

| USB Drive | 4 GB |
| Boot | UEFI or legacy BIOS |

| Component | Recommendation |
|---|---|

| Memory | 8 GB RAM or more |
| Storage | 40 GB or more, preferably SSD |
| Display | Full HD |
| USB Drive | 8 GB or larger |
| Boot | UEFI |

> **Secure Boot:** Secure Boot should currently be considered unsupported unless it has been specifically validated on your hardware.

## Try DeshiOS Without Installing

You don't need to immediately replace your existing operating system.

DeshiOS provides a Live environment that can be started directly from a USB drive.

The basic process is:

1. Download the DeshiOS ISO.
2. Download a USB writing tool such as Rufus, balenaEtcher or another compatible utility.
3. Connect a USB drive.
4. Write the DeshiOS ISO to the USB drive.
5. Restart your computer.
6. Open your computer's boot menu.
7. Select the USB drive.
8. Start DeshiOS.
9. Explore the Live environment.
10. Install DeshiOS only when you are ready.

Read the complete installation guide at **[deshios.com/install](https://deshios.com/install)**.

> Back up important files before modifying disks or partitions. DeshiOS 26.08 RC1 is a development release.
