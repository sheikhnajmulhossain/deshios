# DeshiOS

DeshiOS is an open source desktop operating system project developed in Bangladesh.

DeshiOS focuses on a clean, responsive and customizable desktop experience while giving users freedom and control over their computers.

## Current Release

**DeshiOS 26.08 RC1**

- Architecture: AMD64
- Status: Release Candidate
- Desktop: GNOME 48
- Foundation: Debian 13
- Installer: Calamares

DeshiOS is under active development. The current release is intended for testing and feedback.

## Download

Official website: https://deshios.com

ISO images should be distributed through GitHub Releases rather than committed directly to this repository.

## What is DeshiOS?

DeshiOS is a Linux distribution. The current release uses Debian as its foundation and GNOME as its desktop environment. DeshiOS adds its own desktop configuration, branding, installer configuration, boot experience, hardware and firmware selection, default applications and other system changes.

DeshiOS builds on Debian, GNOME, the Linux kernel and the wider free and open source software community.

## Goals

- Clean desktop experience
- Strong performance on modest hardware
- User freedom and control
- Graphical installation
- Live USB support
- Good laptop hardware compatibility
- Open source development
- Distinctive DeshiOS visual identity

## Requirements for 26.08 RC1

Minimum: 64 bit Intel or AMD CPU with at least 2 cores, 4 GB RAM, 20 GB free storage, 1024 × 768 display and a 4 GB USB drive.

Recommended: modern 64 bit Intel or AMD CPU, 8 GB RAM or more, 40 GB or more SSD storage, Full HD display and an 8 GB or larger USB drive.

UEFI and legacy BIOS boot tooling are included. Secure Boot should currently be considered unsupported unless specifically validated.
