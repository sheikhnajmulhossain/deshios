## About DeshiOS

DeshiOS is an open source desktop operating system focused on providing a clean, responsive and customizable computing experience.

It is designed for everyday desktop use while giving users the freedom and flexibility expected from a modern Linux distribution.

The project is currently under active development, and public releases are available for testing and feedback.

## Why DeshiOS?

### Clean Desktop

A modern desktop experience designed to remain simple, familiar and comfortable for everyday use.

### Lightweight Approach

DeshiOS aims to provide good performance without requiring unusually powerful hardware.

### Freedom and Control

Users have control over their system, applications and desktop without unnecessary platform restrictions.

### Try Before Installing

Boot DeshiOS directly from a USB drive and explore the operating system before deciding whether to install it.

### Graphical Installer

A graphical installation experience makes installing DeshiOS easier for normal desktop users.

### Customizable

Change applications, extensions, appearance and system configuration according to your own preferences.

### Open Source

DeshiOS is developed as an open source project and builds upon the wider Linux and free software ecosystem.

---

## What is DeshiOS?

DeshiOS is a Linux distribution.

The current DeshiOS release uses **Debian 13** as its foundation, **GNOME 48** as its desktop environment and **Calamares** for graphical installation.

DeshiOS combines these technologies with its own branding, desktop configuration, boot experience, installer configuration, selected applications, hardware support and system changes.

The project builds upon Debian, GNOME, the Linux kernel and the work of the wider free and open source software community.

| Component | Recommendation |
|---|---|

| Display | Full HD |

> Secure Boot should currently be considered unsupported unless specifically validated on your hardware.

Future DeshiOS releases may have different hardware requirements.

## Try DeshiOS

You can try DeshiOS without immediately installing it on your computer.

1. Download the DeshiOS ISO.
2. Write the ISO to a USB drive using Rufus, balenaEtcher or another compatible tool.
3. Restart your computer.
4. Open your computer's boot menu.
5. Select the USB drive.
6. Start DeshiOS.
7. Explore the Live environment.
8. Install DeshiOS when you are ready.

For detailed instructions, see the **[Installation Guide](https://deshios.com/install)**.

> DeshiOS 26.08 RC1 is a development release. Back up important data before modifying disks or partitions.
